# Web 攻击面方法论（playbook）

按阶段推进，每阶段以证据集合定进入下一阶段的资格。

1. 可达：对目标 URL 逐个 GET 确认（状态码 + 字节数记线索）；不可达的目标如实记录，不进后续阶段。
2. 指纹：响应头/正文特征、错误页形态记成指纹线索——后续阶段靠它区分 catch-all 与真实差异。
3. 枚举：常见敏感路径（robots.txt、.well-known、管理入口）逐条请求，每条以 path=状态 落账。
4. 面发现：登录表单、上传点、API 边界、跨目录跳转记成线索集群；此时只描述「存在什么面」，不下「可利用」的结论。
5. 复核归档：复核判据里的覆盖度（族:条数），逐条比对该任务产出的线索数；不足就列出缺口交回 core——不许为了收满而伪造观察。
