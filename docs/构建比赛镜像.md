# 构建比赛镜像（自己打包）

## 一键

```bash
cd /home/kali/secpt
bash scripts/build-agent-image.sh
# 产物: ./agent.tar.gz（约 1.5GB，gzip 校验通过）
```

可选：

```bash
KEEP_BUILDER=0 bash scripts/build-agent-image.sh   # 完成后删除 buildx 构建缓存（省几 GB）
LOAD=1 bash scripts/build-agent-image.sh           # 额外 docker load + 无凭证冒烟（较慢）
```

## 前置条件

- Docker + docker buildx（本机已验证）
- 构建期网络：Kali apt（清华镜像）、PyPI（清华镜像）、Docker Hub（registry mirrors）
- 磁盘 ≥ 15GB 空闲（构建缓存 + 4.6GB 镜像 + 1.5GB 压缩包）
- 首次约 20-30 分钟；复用构建器缓存后约 5-10 分钟

## 它做了什么

1. `scripts/prepare-image-seed.py`：把 `var/knowledge/playbooks` 与 `experiences.jsonl`
   脱敏（flag/token/私钥/UUID 打码）后写入 `seed/`。
2. 创建独立 buildx 构建器 `secpt-export`（docker-container driver + Docker Hub 镜像加速）。
3. `docker buildx build --output type=docker,dest=/tmp/secpt-agent-export.tar`
   —— **绕开本机 `docker save` 死锁**，直接导出 docker 格式 tar。
4. 校验 tar：镜像名、无 `DEEPSEEK_API_KEY`/`BENCHMARK_TOKEN` 环境变量、Entrypoint 存在。
5. gzip 成 `agent.tar.gz`，校验 gzip 完整性 + 3GB 上限。

## 手工等价命令（不想用脚本时）

```bash
cd /home/kali/secpt
python3 scripts/prepare-image-seed.py

cat > /tmp/secpt-buildkitd.toml <<'EOF'
[registry."docker.io"]
  mirrors = ["docker.m.daocloud.io", "docker.mirrors.ustc.edu.cn", "docker.1ms.run", "hub.rat.dev"]
EOF
docker buildx create --name secpt-export --driver docker-container \
  --config /tmp/secpt-buildkitd.toml --bootstrap

docker buildx build --builder secpt-export --progress=plain \
  --output type=docker,dest=/tmp/secpt-agent-export.tar \
  -f docker/agent.Dockerfile -t secpt-agent:latest .

gzip -c /tmp/secpt-agent-export.tar > agent.tar.gz
gzip -t agent.tar.gz && ls -lh agent.tar.gz
```

如果换到一台 `docker save` 正常的机器，也可以用传统方式：

```bash
docker build -f docker/agent.Dockerfile -t secpt-agent:latest .
docker save secpt-agent:latest | gzip > agent.tar.gz
```

## 本地验证

```bash
docker load -i agent.tar.gz
# 无凭证：应立即报“缺少 BENCHMARK_TOKEN”退出
docker run --rm secpt-agent:latest

# 带凭证跑完整入口（会消耗 LLM token；旧任务 token 会得到 409/404，属正常）
docker run --rm --env-file .env secpt-agent:latest

# 检查工具/插件
docker run --rm --entrypoint sh secpt-agent:latest -c \
  'for c in nmap gobuster ffuf sqlmap hydra john hashcat nikto nuclei subfinder radare2 gdb checksec qemu-x86_64 chromium; do command -v $c || echo MISSING:$c; done'
```

## 运行时环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 默认端点必填 | DeepSeek 官方 key；用自定义端点时可用 `SECPT_MODEL_API_KEY` |
| `BENCHMARK_TOKEN` / `BENCHMARK_BASE_URL` | 平台自动注入 | 题面占位符会被忽略，以环境变量为准 |
| `SECPT_MODEL_BASE_URL` | 可选 | 任意 OpenAI 兼容网关地址（含 `/v1` 等前缀） |
| `SECPT_MODEL_NAME` | 可选 | 模型名；覆盖主模型/回退模型/角色模型的 model id |
| `SECPT_MODEL_API_KEY` | 可选 | 自定义端点 key（优先于 `DEEPSEEK_API_KEY`） |
| `SECPT_MODEL_AUTH_HEADER` / `SECPT_MODEL_AUTH_SCHEME` | 可选 | 非标准鉴权头（默认 `Authorization: Bearer`；Azure 可 `api-key` + 空 scheme） |
| `SECPT_MODEL_CHAT_PATH` | 可选 | 自定义 chat 路径（默认 `/chat/completions`；base 已含则不重复拼接） |
| `SECPT_MODEL_EXTRA_HEADERS` | 可选 | 额外请求头 JSON（如 `{"X-Tenant":"t1"}`） |
| `SECPT_MODEL_PRIMARY` / `SECPT_MODEL_FALLBACK` | 可选 | 官方/前缀模型的名称（默认 deepseek-v4-flash） |
| `SECPT_BENCHMARK_WORKERS` | 可选 | 默认 3（平台容器上限 3） |
| `SECPT_CAMPAIGN_ROUNDS` | 可选 | 默认 3（自动多轮重试） |
| `SECPT_BENCH_BROWSER` | 可选 | 默认 0；设 1 启用 browser_*（系统 chromium 已内置） |
| `SECPT_VPN_PROBE_URL` | 已设 off | 比赛环境不依赖 VPN，勿改 |

自定义端点示例（平台运行时环境变量）：

```
SECPT_MODEL_BASE_URL=https://your-gateway.example/v1
SECPT_MODEL_NAME=your-model-name
SECPT_MODEL_API_KEY=sk-xxxx
# 此时不需要 DEEPSEEK_API_KEY
```

也可用 provider 前缀方式：`SECPT_MODEL_PRIMARY=mygw/qwen3-32b` +
`SECPT_MODEL_BASE_MYGW=...` + `SECPT_MODEL_KEY_MYGW=...`（前缀统一为大写下划线）。

## 常见问题

- **`docker save` 卡住 0 字节**：这是本机 Docker 导出路径死锁；用本脚本的 buildx 导出即可。
- **buildx 拉不到 `kalilinux/kali-rolling`**：构建器没配 registry mirror；用脚本创建，或手工写
  `/tmp/secpt-buildkitd.toml` 后 `docker buildx create --config ...`。
- **Kali apt 很慢**：Dockerfile 已切清华 HTTP 镜像（Kali 基础镜像缺 CA，HTTPS 会证书失败）。
- **playwright 下载 Chromium 慢**：已改用 Kali `chromium` + playwright 系统浏览器回退，不下载 CDN。
- **超过 3GB**：当前 1.5GB；若增工具，优先裁 `qemu-user`、`hashcat`、`chromium`、字典。
- **镜像里不能有凭据**：`.dockerignore` 已排除 `.env`/`vpn`/`var`；种子脚本会再脱敏；
  自检会断言环境变量里没有 key/token。
