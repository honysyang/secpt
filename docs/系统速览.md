# 系统速览 · 5 分钟到 30 分钟读懂 secpt

> 本文是唯一推荐阅读入口。读完"3 分钟"部分你就能向别人说清这个系统；
> 读完"10 分钟"部分你就掌握了全部核心机制；之后按需深入。

---

## 30 秒 · 它是什么

**一句话**：secpt 是一个自主渗透/挖洞 Agent 系统——给一个题目或目标，它自动完成
侦察→攻击→验证→出报告全过程，并且越用越聪明（每次运行沉淀经验）。

**一条命令**：
```bash
secpt solve challenges/rois-saml-sso        # 唯一入口，全自动
secpt watch <job_id>                        # 实时看每一步思考/工具/响应
```

**三条设计哲学**（读懂这三句 = 读懂一半系统）：
1. **数据驱动**：场景差异（CTF/渗透/挖洞/审计）全是 YAML 表达，零硬编码靶场逻辑
2. **append-only 事件溯源**：运行全程落盘为不可变事件流，评判/续跑/回放/学习全部由它衍生
3. **最小充分打法**：简单任务零开销单链，失败自动升级意图驱动（planner/frontier）

## 3 分钟 · 一次任务的完整旅程

```
你:  secpt solve <目录>
系统:
 ① 题面解析      读 test.md/题目.md，正则抽入口 URL，解压附件
 ② 类型路由      profile 自动路由（ctf/hunter/codeaudit…，规则+LLM）
 ③ 知识装配      专项先验(prior) + 历史经验(top-3) 注入 system prompt
 ④ 执行          Engine 主循环：模型 ⇄ 工具（bash/read/write/list + 插件）
                 ├─ 上下文治理：compaction(0.72批量) / rollover(0.95) 防撑爆
                 ├─ 资源预算：步数/墙钟/成本；卡死自动换层提醒
                 └─ 打不动？自动换路线重试 → 再不行升级 frontier 意图驱动
 ⑤ 评判          AI 评判链：反作弊→ground truth→Jev→LLM judge→verdict.json
 ⑥ 沉淀          LLM 蒸馏经验 → 经验库（下次同类任务直接带打法）
```

**产物**（都在 `var/jobs/<job_id>/`）：
`events.jsonl`（逐步完整交互日志）· `ws/`（模型工作区+脚本）·
`verdict.json`（评判）· `rounds/`（断点快照）

## 10 分钟 · 六张机制卡片

### ① 引擎（心脏） `runtime/engine.py` ~650 行
单链 function-calling 主循环。**四条红线**：messages 整条 append 不重建 /
assistant 原样落盘 / tool 结果回灌同链 / ANSWER 自宣告终止。
唯一允许删改两处：compaction 与 rollover。bash 工具 argv 执行**禁 shell=True**
（白名单 + 元字符检查），Docker 沙箱下进容器执行。

### ② 评判 `evaluation/`
**不依赖 flag 正则**——判的是"证据是否满足完成条件"：
反作弊（幻觉检测/本地答案直读）→ ground truth 确定性比对 → Jev 高速门控
（无 key 自动降级）→ LLM judge 终裁 → heuristic 兜底，永不抛异常。

### ③ 记忆（三库一图） `learning/` `intel/` `knowledge/`
| 记忆 | 载体 | 写入 |
|---|---|---|
| 先验（人策划） | `knowledge/priors/*.md` | 关键词自动匹配 |
| 经验（机学） | `var/knowledge/experiences.jsonl` | 每次运行后 LLM 蒸馏 |
| 图记忆 | `intel/`（资产图+探索血缘图） | 程序自动写（规则能写的不让 LLM 写）|

图记忆三招：**联想召回**（关键词命中→1 跳血缘邻居）、**冷节点压缩**
（图结构判冷热+签名缓存）、**覆盖度**（挖洞最怕自以为测完了）。

### ④ 作业 `core/job/`
进程池隔离（每 job 一 worker）+ 心跳/stuck 检测 + SQLite 三表 +
**断点续跑**（round 快照，首条 system 原样复用保 prefix cache）+ 协作式取消。

### ⑤ 挖洞交付 `findings/` `report/` `traffic+evidence/`
findings 验证纪律（inferred→confirmed 只有对抗式复现一条路径，代码级强制）→
CWE 映射（幻觉编号硬校验）→ 报告（md/md-zip 证据包，证据版本一致性）→
流量证据（MITM 录制，finding 自动绑定原始报文）。

### ⑥ 意图驱动 `core/orchestrator/frontier.py`
深利用链场景：planner 每轮新会话产意图入 Frontier（SQLite 持久化 todolist），
worker（=单链引擎）逐条执行，深度优先 + 否定记账。**普通任务零开销走不到这里**。
