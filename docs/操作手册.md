# secpt 操作手册（每次照此执行）

> 系统已自动化：任务路由 / 附件下载解压 / 先验匹配 / 评判 / 经验沉淀 / VPN / 沙箱镜像。
> 你唯一要做的就是**第 2 节的启动命令**和（可选）第 4 节的干预命令。

---

## 1. 一次性准备（已做则跳过）

```bash
cd /home/kali/secpt
python -m venv .venv && source .venv/bin/activate && pip install -e ".[dev]"

cp .env.example .env
# 编辑 .env，至少填：DEEPSEEK_API_KEY
# benchmark 评测再加：BENCHMARK_TOKEN / BENCHMARK_BASE_URL / SECPT_VPN_*
# 网关是 128k 上下文时已内置 SECPT_CONTEXT_WINDOW=128000

make sandbox-image           # Web 沙箱镜像（约 1 分钟）
make sandbox-pwn-image       # pwn/crypto 镜像（约 7 分钟，做一次即可）

secpt doctor                 # 全绿即可
```

## 2. 启动任务（唯一要记住的命令）

```bash
cd /home/kali/secpt && .venv/bin/python -u -m secpt.cli.app solve <题目目录> --wall 0 2>&1 | tee logs/run-$(date +%H%M).log
```

- `<题目目录>`：包含 `题目.md`/`test.md` 的目录（如 `challenges/bbox`）
- 系统自动完成：题面附件 URL 下载解压 → 任务类型路由（ctf/pwn/crypto/hunter/benchmark…）
  → 专项先验注入 → 选对沙箱镜像 → 执行 → 评判 → 经验沉淀 → 可读日志落盘
- `--wall 0` 不限时（长任务）；普通题可省略
- 日志自动落 `logs/`（`<job_id>.log` 系统可读版 + 你的 tee 副本），无需手动管理
- benchmark 评测加 `--vpn`（自动拉起/复用 VPN）；其余题不需要

## 3. 观察与日志（另开终端）

```bash
secpt watch <job_id>              # 实时彩色日志（job_id 启动时打印；至终态自动收尾）
secpt logs export <job_id> -o run.md -f md    # 导出可读日志（txt/md/json）
secpt jobs / status <job_id>      # 任务列表 / 详情
```

## 4. 干预（可选，跑分/长任务最有价值）

```bash
secpt steer <job_id> "提示"       # 中途纠偏，下一步即生效（不打断任务）
secpt intent add --job <base> "做某事"  # 人工直投意图（base=任务 job 号；planner 自动暂停让位）
secpt intent set --job <base> <id> -p 9 # 改意图（优先级/判据/标题；仅 open/blocked）
secpt intent rm  --job <base> <id>      # 撤回跑偏的意图（仅 open/blocked）
secpt pending → approve/deny <id> # 高危命令人工审批（rm -rf 等被拦时）
```

## 5. 出成果（挖洞/评测后）

```bash
secpt findings                    # 漏洞库（inferred/confirmed 分级）
secpt verify <finding_id>         # 对抗式复现（confirmed 的唯一升级路径）
secpt report <job_id> -f md-zip   # 报告 + 证据包
secpt metrics                     # 成功率/误报率/成本/干预次数（--snapshot 记趋势）
secpt archive <job_id>            # 归档本次运行（见第 7 节结构）
```

## 6. 异常处置速查

| 现象 | 处置 |
|---|---|
| `环境变量未设置，已中止` | 题面引用的变量没配：按提示 export 或写进 .env 再跑 |
| `[vpn] 启动失败: sudo` | 先 `sudo /home/kali/secpt/.venv/bin/secpt vpn up` 一次；或配置 NOPASSWD（见 .env.example） |
| `rm -rf 等被拦 ⏸` | `secpt pending` 查看 → `secpt approve <id>` 放行 / `deny` 拒绝 |
| 靶场 502/超时 | 平台实例过期，非系统问题——换新实例更新题面地址 |
| 中断续跑 | `secpt resume <job_id>`（benchmark 类直接重跑更干净：平台幂等，已通题自动 duplicate） |
| 无 key 演练 | `SECPT_FAKE_LLM=1 secpt solve <目录>`（全链路干跑） |

## 7. 日志与数据存储结构（归档标准）

### 7.1 单次任务落盘（`var/jobs/<job_id>/`）

```
var/jobs/<job_id>/
├── task.yaml          # 任务快照（TaskSpec+run_config，resume 依据）
├── events.jsonl       # ★ 完整事件流（append-only）：每步思考/工具调用/响应/发现/
│                      #   操舵/审批/压缩/轮转——评判、回放、审计的唯一事实源
├── run.log            # 可读日志（solve 结束时自动生成，watch 同款渲染）
├── verdict.json       # AI 评判结论（complete/confidence/method/反作弊）
├── rounds/NNN.messages.json   # 断点快照（resume 从这里续）
├── ws/                # 模型工作区（脚本/利用代码/产物）
│   ├── transcript.json        # 最终对话链全量
│   ├── ATTACHMENTS.md         # 附件索引（绝对路径+symlink）
│   └── attachments/           # 附件源码 symlink
└── report.md          # 阶段性报告
```

### 7.2 全局数据（`var/`，跨任务累积，越用越厚）

```
var/
├── secpt.sqlite       # 作业+事件库（jobs/events 表，search_traces 的底座）
├── findings.sqlite    # 漏洞库（9 态分诊，跨任务存活）
├── intel.sqlite       # 双图记忆（资产图+探索血缘图+冷压缩账本）
├── frontier.sqlite    # 意图队列（frontier 模式 todolist）
├── steer.sqlite       # 人工操舵留痕
├── intercept.sqlite   # 拦截规则+审批记录
├── knowledge/experiences.jsonl   # 经验库（蒸馏沉淀，启动时注入）
├── evidence/blobs/    # 流量证据（SHA-256 内容寻址，报告绑定）
├── traffic/<job>.sqlite          # 任务级 MITM 流量（hunter 录制）
├── metrics_history.jsonl         # 指标快照（--trend 对比用）
└── audit/             # 审计日志
```

### 7.3 归档标准动作

```bash
secpt archive <job_id>     # 打包 var/jobs/<id> → archive/runs/<id>.tar.gz 并清理 ws 大文件
```

归档约定：
- **要长期保留**：`events.jsonl` / `run.log` / `verdict.json` / `task.yaml` / `ws/` 里的利用脚本
- **可丢弃**：`rounds/`（断点快照，归档时剔除）、`ws/transcript.json`（events 可重建）
- **全局库不动**：findings/intel/experiences 是资产不是日志，只备份不清理（`cp var/*.sqlite backup/`）
- 日志文件命名：`run-<HHMM>.log`（tee 终端副本）与 `<job_id>.log`（系统可读版），都在 `logs/`；归档以 `var/jobs/<id>/` 为准

## 8. 一页速记（贴墙版）

```bash
# 启动
secpt solve <题目目录> --wall 0 2>&1 | tee run-$(date +%H%M).log
# benchmark 评测
sudo /home/kali/secpt/.venv/bin/secpt vpn up
cd /home/kali/secpt && .venv/bin/python -u -m secpt.cli.app solve challenges/Cybench --vpn --wall 0 2>&1 | tee tsec-run-$(date +%H%M).log
# 观察 / 干预 / 成果
secpt watch <id> │ secpt steer <id> "…" │ secpt report <id> -f md-zip │ secpt archive <id>
```
